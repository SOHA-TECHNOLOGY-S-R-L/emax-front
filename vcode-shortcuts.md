### ShotCuts para Visual Code

```
Ctrl + b            # Toogle panel izquierdo
Ctrl + w            # Cierra ventana selccionada
Ctrl + Shift + e    # Muestra explorador panel izquierdo
Ctrl + Shift + x    # Muestra extensiones panel izquierdo
Ctrl + Shift + p    # Buscador de comando
Alt + Shif + a      # Comenta porciond e código
Alt + Shift + f12    # Referencias que usan el método
Alt + <-            # Ir uno hacia atras
Alt + ->            # Ir uno hacia adelante
Alt + Shift + &uarr  # Duplica linea hacia arriba
Alt + Shift + &darr  # Duplica linea hacia abajo
Alt + Shift + f     # Formatea código
Ctrl + p            # Busca archivo
Ctrl + Shif + o      # Muestra, propiedades, metodos, del componente TS
Ctrl + f            # Busca por palabra
Ctrl +Shift + f     # Busca avanzada por panel
Ctrl + g            # Ir a linea
Ctrl + e            # Archivos recientes
Ctrl + espacio      # Muestra atributos de la etiqueta
Ctrl + Shift +espacio      # Muestra parametros del método
Ctrl + .            # Busca importaciones automaticas

```
